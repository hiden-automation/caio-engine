Política de Privacidade — JARVIS

Última atualização: 6 de outubro de 2026

JARVIS é uma ferramenta pessoal, de uso exclusivo do seu proprietário (conta GitHub hiden-automation), que cria rascunhos de conteúdo e, somente após aprovação manual do proprietário, os publica nas contas dele próprio no Instagram, Threads, LinkedIn, X, TikTok e YouTube.

Dados coletados

O JARVIS não coleta dados de terceiros nem de visitantes. Ele acessa apenas as contas do próprio proprietário, mediante autorização OAuth concedida por ele, para: publicar conteúdo aprovado, ler métricas de desempenho das próprias publicações e ler comentários das próprias publicações.

Armazenamento

Tokens de acesso ficam em segredos criptografados do GitHub Actions. Conteúdos, métricas e decisões ficam em um repositório privado do GitHub do proprietário. Nada é vendido ou compartilhado.

Exclusão

O proprietário pode revogar o acesso a qualquer momento nas configurações de cada plataforma e apagar os dados excluindo o repositório privado.

Privacy Policy (English)

JARVIS is a personal tool used solely by its owner. It drafts content and, only after the owner's manual approval, publishes it to the owner's own Instagram, Threads, LinkedIn, X, TikTok and YouTube accounts. It does not collect data from any third party. It only accesses the owner's accounts through OAuth authorization granted by the owner, to publish approved content and read performance metrics and comments of the owner's own posts. Tokens are stored as encrypted GitHub Actions secrets; content and metrics are stored in the owner's private GitHub repository. Nothing is sold or shared. Access can be revoked at any time on each platform. Contact: hiden.automacao@gmail.com.
